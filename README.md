# Прогнозирование отказов насосного обоорудования

Автор: Гайдукова Дарья Дмитриевна

## Описание проекта

Проект посвящён предиктивному обнаружению отклонений в работе насосного оборудования.

_Цель проекта_ — Разработка программного сервиса для предиктивного обнаружения отказов насосного оборудования (центробежных насосов).

Предиктивная аналитика позволяет:

- заранее выявлять потенциальные сбои,
- сокращать простой оборудования,
- снижать затраты на обслуживание и ремонт.

Предлагаемая модель решает задачу бинарной классификации состояния оборудования с определением вероятности состояния отказа:

### Формат входных и выходных данных

_Входные данные_

Данные представлены в формате CSV (хранение данных - Yandex Cloud Object Storage S3) и содержат следующие признаки:

| Признак     | Описание                        |
| ----------- | ------------------------------- |
| Temperature | Температура корпуса насоса      |
| Pressure    | Давление                        |
| Vibration   | Уровень вибрации                |
| Flow_Rate   | Расход перекачиваемой жидкости  |
| RPM         | Скорость вращения ротора насоса |
| Failur flag | Целевая метка (0 / 1)           |

_Выходные данные модели_

- вероятность возможности отказа насоса

- предсказанный класс (0 или 1)

### Метрики качества

В датасете наблюдается сильный дисбаланс классов, поэтому используются следующие метрики:

- _F1-score_

- _Precision_

- _Recall_

- _ROC-AUC_

- _PR-AUC_

**Основной метрикой для итоговой оценки является PR-AUC**

### Setup

1. Склонировать репозиторий:

```
git clone <ссылка на репозиторий>
cd <ссылка на репозиторий>
```

2. Задать окружение:

```
python -m venv venv
venv\Scripts\activate      # Windows
source venv/bin/activate  # Linux / macOS
```

3. Проверить, что код проходит проверку pre-commit:

```
pre-commit run -a
```

6. Поднять сервис:

```
docker-compose up --build
```
